Research · CV

Fisheye Perception Pipeline

Self-calibration via straight-line invariance with a field-preserving polynomial f(r) = r + k₁r³ − k₁r⁵. YOLO11n-seg reaches box mAP50 = 0.7441 on FishEye8K at 2.84M parameters.

View project →

Research · Depth

Radius-aware Fisheye Depth (DFDNet)

A radial-dependent point spread function for fisheye depth: outer-ring RMSE 0.0449 vs. Gaussian baseline 0.0756 (~41% better); JPEG+vignette augmentation cut validation RMSE from 0.1425 to 0.0738.

View project →

Robotics · Haptics

OmniBelt — Dual-Fisheye Vibration Belt

185° dual-fisheye perception on Raspberry Pi 5 driving a 12-channel haptic belt. The fast loop runs segmentation, the slow loop queries a VLM — both mapped onto 12 vibration sectors.

View project →
